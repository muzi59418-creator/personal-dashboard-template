# 个人工作仪表板模板

这是一个基于 React 的个人工作仪表板模板，适合用来记录工作内容、工作日记、临时想法和项目进度。项目默认只使用浏览器本地存储，不需要服务器，也不会把数据上传到云端。

本仓库是公开开源模板，只包含通用中文演示数据，不包含任何个人工作数据、账号、联系方式、图片识别信息或内部业务信息。

当前版本：v1.3.9

## 功能列表

- 首页概览：查看近期事项、工作完成情况、日记和项目推进情况。
- 今日工作台：查看优先处理、今日例行、项目推进和今日已完成。
- 工作内容：新增、编辑、删除任务，按分类、状态、截止日期和计划执行日管理。
- 工作模板：从模板预填新增工作，并管理可复用的非周期工作模板。
- 例行工作：配置每天、中国法定工作日、每周、每月或指定日期的重复事项，支持法定节假日顺延、暂停恢复和单次跳过。
- 工作日记：记录每日总结、问题和后续行动。
- 灵感：保存灵感、待整理内容和图片附件。
- 项目管理：维护项目背景、目标、推进清单、风险、自动进度和复盘；项目详情使用右侧抽屉，并支持高频字段快捷编辑。
- 分类管理：自定义工作分类和颜色。
- 设置 / 备份：导入、导出、清空本地数据，并恢复演示数据。

## 页面说明

- 首页：适合每天打开后快速查看当前状态。
- 工作内容：适合管理待办、进行中和已完成事项。
- 工作日记：适合记录每天的复盘和关键进展。
- 灵感：适合先保存零散内容，再转化为任务或日记。
- 项目管理：适合跟踪中长期项目。
- 分类管理：适合调整自己的分类体系。
- 设置 / 备份：适合管理浏览器本地数据。

## 技术栈

- React
- TypeScript
- Vite
- lucide-react
- 浏览器 localStorage

## 本地启动

先安装 Node.js，然后在项目目录中运行：

```bash
npm install
npm run dev
```

启动后，终端会显示本地访问地址，通常是：

```text
http://localhost:5173/
```

## 构建命令

```bash
npm run build
npm run lint
```

构建产物会生成在 `dist` 目录中。`dist` 已加入 `.gitignore`，不会提交到仓库。

## 数据存储方式

所有数据默认只保存在当前浏览器的 localStorage 中。换浏览器、换设备或清空浏览器数据后，本地数据不会自动同步。

建议在“设置 / 备份”页面定期导出 JSON 备份。

v1.3.0 起项目进度按推进事项自动计算。v1.3.9 优化今日工作台、项目详情抽屉、设置 / 备份页和更新日志版本展示，但不改变数据结构和本地存储口径。导出 JSON 会包含 `version`、`appVersion` 和 `schemaVersion`，旧版 JSON 备份仍可导入。读取旧本地数据时会先保存迁移前备份，再补新字段。

## v1.3.0 项目推进清单

- 旧项目步骤命名统一升级为“项目推进清单”，“步骤”统一升级为“推进事项”。
- 推进事项可先打开新增工作弹窗，再由用户确认保存为工作内容。
- 项目下一步动作可转为今日计划工作。
- 项目进度按已完成推进事项数量自动计算；无推进事项项目显示“未拆分推进事项”，不参与平均进度。
- 旧项目手动进度字段继续保留，但新版页面不再用它展示项目进度。

## 如何清空数据

进入“设置 / 备份”页面，点击“清空本地数据”。清空后当前浏览器中的任务、日记、想法和项目会变为空数据。

## 如何恢复演示数据

进入“设置 / 备份”页面，点击“恢复演示数据”。这个操作会用模板自带的演示数据覆盖当前浏览器本地数据。

## 部署到 Vercel

1. 使用 GitHub Template 创建自己的仓库。
2. 登录 Vercel，选择 “Add New Project”。
3. 导入自己的 GitHub 仓库。
4. Framework Preset 选择 Vite。
5. Build Command 使用 `npm run build`。
6. Output Directory 使用 `dist`。
7. 点击 Deploy。

## 部署到 Cloudflare Pages

1. 使用 GitHub Template 创建自己的仓库。
2. 登录 Cloudflare Dashboard，进入 Workers & Pages。
3. 选择 “Create application” 后选择 Pages。
4. 连接自己的 GitHub 仓库。
5. Framework preset 选择 Vite。
6. Build command 填写 `npm run build`。
7. Build output directory 填写 `dist`。
8. 保存并开始部署。

## 通过 GitHub Template 创建自己的版本

在 GitHub 仓库页面点击 “Use this template”，选择 “Create a new repository”，然后填写你自己的仓库名称。创建后，你可以自由修改演示数据、页面文案、颜色和功能。
